# Implementation Plan: ghost-in-the-audit

Based on `requirements.md` and `design.md`. `R<requirement>.<clause>` identifies an acceptance criterion (for example, R7.20 is requirement 7, clause 20). `D<section>` identifies a section of design.md, and `T<n>` identifies an item in the platform calibration checklist in design.md section 11. Tasks are ordered by dependency. **Bold** tasks are prerequisites for subsequent tasks and must pass before proceeding to the next section. All runtime code goes in `.kiro/scripts/` and uses only the Python 3.9+ standard library (D1).
